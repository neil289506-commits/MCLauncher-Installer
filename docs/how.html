How it works

下載機制

IDM 優先,沒有 IDM 就用內建 curl 分段下載。

流程

選擇啟動器

從 11 個啟動器中挑一個。

選擇版本

選擇安裝版或可攜版。

選擇儲存位置

依提示選擇儲存位置。

選擇下載器

若偵測到 IDM,選擇使用 IDM 或內建下載器。

完成

等待下載完成,必要時執行下載好的安裝程式。

IDM

透過登錄檔與常見安裝路徑偵測 IDMan.exe,以 /d(網址)、/p(儲存資料夾)、/f(檔名)、/n(靜默)命令列參數交給 IDM。

內建 curl 下載器

  • 以 curl -sIL 取得檔案大小。
  • 5 MB 以上且伺服器支援時,用 HTTP Range 分成 8 段平行下載,完成後合併;較小的檔案單線下載。
  • 下載時會跳出一個終端機視窗顯示進度。
  • 所有 curl 呼叫都帶 --ssl-no-revoke,略過 Windows Schannel 的憑證撤銷檢查。

沒有副檔名的轉址連結(例如 aka.ms)會用指定的檔名儲存,例如 MinecraftInstaller.exe。
