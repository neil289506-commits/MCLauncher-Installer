自行建置

git clone https://github.com/neil289506-commits/MCLauncher-Installer.git
cd MCLauncher-Installer
cargo build --release
# 輸出:target/release/mc_launcher_installer.exe
cargo run   # 開發時直接執行

相依套件:eframe / egui 0.29、image、open、winreg;release 設定為 LTO 並移除符號。
